# Application of Machine Learning Methods to Forecast Daily Retail Sales Turnover

This repository contains the source code, processed outputs, figures, and result tables for the research paper **"Application of Machine Learning Methods to Forecast Daily Retail Sales Turnover"**, conducted on the Rossmann Store Sales dataset.

## 📂 Repository Structure

```text
├── rossmann/                                        # Output directory (mirrors the Google Drive project folder)
│   ├── figures/                                     # Generated plots, visualizations, and diagnostic charts
│   ├── processed/                                   # Preprocessed datasets and intermediate feature engineering files
│   └── tables/                                      # Evaluation metrics, model comparison tables, and summary results
├── (code) Application of Machine Learning
|   Methods to Forecast Daily Retail Sales Turnover  # Main Jupyter Notebook (.ipynb) with full experimental pipeline
└── README.md                                        # Project documentation

```
## ⚠️ Note on Opening Code Files (`.ipynb`)

Due to GitHub's rendering limitations, the main Jupyter Notebook file (`(code) Application of Machine Learning Methods to Forecast Daily Retail Sales Turnover`) may sometimes fail to load or display properly directly in the browser. 

If you encounter a rendering error or a blank page:
**Download the file:** Click on the `.ipynb` file in the repository and press the **Download** button to view and run it locally on your machine (via Jupyter Notebook, JupyterLab, or VS Code).
